This module adds a payment method field to sale orders and invoices.

It provides a configurable list of payment methods (Dinheiro, Cartão de Crédito,
Cartão de Débito, Transferência Bancária, Cheque, Boleto Bancário, PIX)
that can be selected on the sale order form and invoice form, below the payment
terms field. New payment methods can be added via the menu Sales > Payment Methods.
The selected payment method is carried over when generating an invoice from a sale order.
